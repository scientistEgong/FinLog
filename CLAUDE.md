# Claude Instructions for FinLog

Before doing any work in this repository:

1. Read [`AGENTS.md`](AGENTS.md) in full. It is the canonical instruction file for all coding agents.
2. Read [`HANDOFF.md`](HANDOFF.md) for the latest known project state.
3. Read [`PROJECT_CHECKLIST.md`](PROJECT_CHECKLIST.md) to understand the current phase and approved next work.
4. Follow [`SECURITY.md`](SECURITY.md) and [`CONTRIBUTING.md`](CONTRIBUTING.md).

If instructions conflict, do not silently choose one. Identify the conflict and ask the developer.

The developer expects careful, incremental engineering:
- inspect before editing;
- preserve approved architecture, folder structure, business rules, and existing naming;
- explain significant proposed changes and wait for approval;
- write descriptive, structured, maintainable code;
- use purposeful comments that explain intent and non-obvious decisions, not comments on every line;
- run relevant checks and report only verified results;
- do not commit, push, or create a pull request unless explicitly asked.

Do not treat this file as a separate or competing policy. Update the canonical rules in `AGENTS.md` when an approved general agent instruction changes.
